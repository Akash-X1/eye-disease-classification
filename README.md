# Eye Disease Classification Using CNN Architectures

## Overview
This group project compares convolutional neural network architectures for classifying eye-disease images. The report evaluates modified VGG-16, AlexNet, and GoogLeNet across four classes: Cataract, Diabetic Retinopathy, Glaucoma, and Normal.

## Project files
- `eye_disease_classification.ipynb` — model-building, training, evaluation, and prediction notebook.
- `project-report.pdf` — project report.

## Requirements
The notebook uses Python deep-learning and data-analysis libraries. Review the import cell in the notebook and install the corresponding packages in your environment. Exact versions should be recorded after verifying the original working environment.

## Dataset setup
The notebook currently contains a local Windows dataset path. Update `DATASET_PATH` to the location of your own authorized copy of the dataset before running it. The dataset itself is not included in this repository.

## Reproducibility notes
- The notebook describes a 70% training, 15% validation, and 15% test split.
- The report and notebook should be checked together before making claims about final results.
- Trained model files and datasets are not included in this initial repository package.
